Comprendre les concepts de l'IA

Du Machine Learning à l'IA Générative : démystifions les termes techniques derrière la magie.

La grande distinction

Générative vs Prédictive

C'est la différence entre analyser et créer.

  • 🔹 IA Prédictive : Analyse des données passées pour prédire un futur probable (ex: score de crédit, météo, recommandations Netflix).
  • ✨ IA Générative : Utilise ses connaissances pour créer de nouveaux contenus originaux (texte, image, code, musique).

Analogie simple

"L'IA prédictive est comme un arbitre qui juge une action. L'IA générative est comme l'artiste qui peint une nouvelle scène."

Exemples IA Prédictive

  • 🌡️ Météo : Prévoir la température de demain.
  • 💳 Banque : Détecter une transaction frauduleuse.
  • 🎬 Netflix : Recommander un film selon vos goûts.
  • 📧 Spam : Filtrer les emails indésirables.

Exemples IA Générative

  • ✍️ ChatGPT : Écrire un poème ou un email.
  • 🎨 Midjourney : Créer une image de paysage.
  • 💻 Copilot : Générer du code informatique.
  • 🎵 Suno : Composer une musique originale.
LLM

Large Language Models

Des modèles entraînés sur des quantités massives de texte pour "prédire le mot suivant".

Multimodalité

Multimodalité

La capacité d'un modèle à traiter et générer différents types de données (texte + image + son).

Hallucinations

Hallucinations

Le phénomène où l'IA génère des informations fausses mais très convaincantes.

Vers l'AGI ?

Aujourd'hui, nous utilisons une IA "étroite" (spécialisée). Le Graal de la recherche est l'AGI (Artificial General Intelligence), une IA capable d'égaler l'intelligence humaine sur n'importe quelle tâche.
